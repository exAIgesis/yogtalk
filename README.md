# YogTalk
xmpp for the rest of us

# Why YogTalk?
XMPP clients, varied as they are, are decent at best, and unusable at worst. YogTalk aims to create a unified XMPP client across platforms by leveraging a multiplatform UI framework, tied to a compiled Ada backend. This software prioritizes consistency and security; as such, RFCs and XEPs will be integrated iteratively.

# LLM Policy
This project does not retain the stance of neither an absolute LLM ban, nor absolute trust in LLM-generated code. As such, authors are expected to audit generated code as appropriate: authors are responsible for the contents of their commits and PRs. Therefore, PRs/commits attributed to an LLM or associated tool (e.g. "co-authored by Claude") are not permitted, and it is encouraged to state whether an LLM was used for the production of code (and preferably what model, since we like data).
